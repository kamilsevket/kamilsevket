### How I work

- **Native Apple stack first** — SwiftUI before web wrappers, SwiftData before sidecar databases, GameKit before custom social stacks.
- **One write lane**, value-typed snapshots, protocols as the only extension point. Strict Swift 6 concurrency.
- **End to end** — design, ship, run the backend, handle the support email. Self-hosted Supabase on Coolify, Cloudflare in front, all on my own name.
